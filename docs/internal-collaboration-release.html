WhatsApp Core · Collaboration release

From a chat inbox to a team workspace.

Summaries now reduce long conversations into a compact view, while private notes, mentions, assignments, replies and resolution keep internal work connected to the exact customer context.

Implemented Browser tested Core-owned data No production changes

How the process works

One permission-scoped path from customer context to accountable team work.

1Open customer

A summarized conversation opens in Compact mode instead of loading the complete transcript first.

2Create internal note

The operator links the note to the contact summary, a topic, or selected messages.

3Mention or assign

Only team members who can access this conversation can be selected.

4Notify

Core creates a durable Frappe notification and sends a realtime refresh to the recipient.

5Reply and resolve

The recipient opens the exact conversation, replies with context, then resolves or reopens the task.

New features

The visible UI and the data contract were changed together.

Conversation viewCompact by default

Conversations with a summary or topics start in Compact mode. “Expand conversation” restores the full message timeline.

ContextNotes against real work

A note can reference a contact summary, topic summary, summary period, or up to 50 messages.

CollaborationMentions and assignment

Up to 20 scoped teammates can be mentioned, with one accountable assignee.

ThreadingReplies keep context

Replies display the original author and note preview, without exposing random database IDs.

WorkflowResolve and reopen

Authors, assignees and managers can update work; resolution records who completed it and when.

NotificationsDurable and realtime

The bell loads permission-scoped Notification Logs. A click marks one read and deep-links to its comment.

Core and Hub responsibility

Internal customer work stays private to the business site.

WhatsApp Core owns

Internal notes, summary links, message links, mentions, assignment, replies, task state, Notification Logs, permissions and the collaboration UI.

WhatsApp Hub owns

Meta credentials, transport, webhook routing, delivery work, templates and relay operations. It does not receive private internal notes.

Permission and integrity rules

  • Conversation scope: every read and write first validates access to the selected conversation.
  • Team scope: mentions and assignment reject users outside the conversation’s eligible team.
  • Reference scope: linked messages and summaries must belong to the same conversation or identity.
  • Mutation scope: only the author, assignee or WhatsApp Manager can edit, resolve, reopen or delete.
  • Notification scope: users only receive and load notifications for conversations they may still access.
  • Query efficiency: users, message previews, summary labels and notification comments are batch hydrated.
